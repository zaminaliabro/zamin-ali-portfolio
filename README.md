# Zamin Ali — Portfolio

Personal portfolio for Zamin Ali, MERN Stack Developer. Dark, animated,
single-page site built with React, Tailwind CSS and Framer Motion.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- React Icons

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build -> dist/
```

## Structure

- `src/data/portfolio.js` — all editable content (profile, skills, projects, services, education)
- `src/components/` — one component per section
- `public/Zamin-Ali-CV.pdf` — resume served by the "Download CV" button
